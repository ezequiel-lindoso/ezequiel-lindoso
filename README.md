Minha trajetória na tecnologia começou movida por uma curiosidade fundamental: **entender como os sistemas funcionam por baixo dos panos e como a engenharia de software pode resolver problemas reais do mercado.** 

Atualmente, curso **Engenharia de Software no UDF Centro Universitário** e dedico meus dias a aprofundar conhecimentos em lógica de programação, arquitetura de sistemas e desenvolvimento web semanticamente estruturado. No nível mais baixo, domino os fundamentos da **linguagem C** (estruturas de dados, ponteiros e manipulação de memória); na camada visual e de aplicação, foco na criação de interfaces fluidas, acessíveis e intuitivas.

Além da formação acadêmica, trago uma veia empreendedora voltada ao mercado **B2B**. Enxergo o código não apenas como instrução para máquinas, mas como o motor para construir produtos escaláveis, ferramentas de segurança de rede e soluções digitais acessíveis que impactam a vida das pessoas e a eficiência das empresas.

🎯 **Minhas metas atuais:**
- 💻 Consolidar arquiteturas de software sólidas para soluções web e sistemas.
- 🛠️ Desenvolver projetos MVP focados em usabilidade e impacto no ecossistema B2B.
- 📈 Expandir conexões e evoluir continuamente em desenvolvimento full-stack e segurança de sistemas.

##relatório:

Ao olhar os perfis de referência no GitHub, percebi que os melhores devs mantêm tudo muito organizado, direto ao ponto e fácil de entender. O que mais me chamou a atenção no Profile README foi como eles explicam rapidamente com o que trabalham, usando ícones e cartões de estatísticas de forma simples, sem deixar a página poluída ou bagunçada. Nos projetos que deixam em destaque, notei que todos têm nomes bem padronizados e trazem um README.md muito bem feito, com imagens, diagramas explicando o projeto e um passo a passo claro de como baixar e rodar o código na máquina. Além disso, repará que todos os repositórios sérios têm arquivos de licença (como a MIT) e o .gitignore configurado certinho para não mandar arquivos desnecessários pro GitHub. Me espelhando nessas boas práticas, resolvi dar uma geral no meu próprio perfil: organizei meus projetos principais na tela inicial, arrumei as explicações de como rodar cada um deles e deixei os repositórios mais limpos e bem documentados. Essa mudança me ajudou a deixar meu GitHub muito mais profissional e pronto para mostrar o que estou aprendendo na prática.
